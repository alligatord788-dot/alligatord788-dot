## About Me

I am a **B.Tech Chemical Engineering student at IIT Delhi** exploring **AI/ML, Data Science, Deep Learning and GenAI**. I like building projects that start from messy data, go through cleaning and modelling, and finally become something useful through dashboards, assistants or clear insights.

- Working on **cancer genomics**, **single-cell/spatial transcriptomics** and transformer-based perturbation analysis.
- Building applied data science projects in **credit risk**, **customer churn**, **financial research automation** and **search systems**.
- Interested in using **Python, Scikit-learn, XGBoost, PyTorch, LangChain, RAG and analytics** to solve real-world problems.
- Comfortable using AI coding assistants to speed up development, debug pipelines and automate repetitive work.
